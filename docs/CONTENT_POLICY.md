# SitaRam — Content Policy

SitaRam enforces strict guidelines to preserve the accuracy and sanctity of the Valmiki Ramayana.

## Rules
1. **No AI-generated text as primary source**: AI is only used to explain human-reviewed source text, never to generate verses or write new stories.
2. **Review status states**:
   - `raw_import`: OCR import completed.
   - `cleaned`: scanning noise and headers removed.
   - `approved_for_app`: verified and verified translation by humans.
3. **No automatic approval**: All imported text must be reviewed and approved manually before release to the client app.
