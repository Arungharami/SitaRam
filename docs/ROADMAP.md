# SitaRam — 7-Kanda Roadmap

Timeline and scope for expanding translation, summary, and audio datasets for all seven Kandas.

## Roadmap Phase Scope

### Phase 1: Bala Kanda (Current)
- Complete English public domain segmentation.
- Bangla translation review and audio narration.

### Phase 2: Ayodhya & Aranya Kandas
- Segment and ingest Sargas.
- Build vector search index updates.

### Phase 3: Kishkindha & Sundara Kandas
- Hanuman's journey details.
- Add character mapping relationships.

### Phase 4: Yuddha & Uttara Kandas
- Complete epic battle details.
- Final cleanups and publication.
